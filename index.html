Alignment

Main axis and cross axis

Main axis = the direction the widgets flow. Cross axis = the other direction.

Column
TextTextText main ↓ cross →
Row
IconIconIcon main → cross ↓
mainAxisAlignment moves widgets along the main axis. crossAxisAlignment moves them along the cross axis.
Mobile App Development · Lecture 05

Students mix these up all the time. Repeat: Column main = down, Row main = right. Ask them to point with their arm.

Alignment

mainAxisAlignment in a Row

Six ways to spread the widgets along the main axis.

MainAxisAlignment.start
MainAxisAlignment.center
MainAxisAlignment.end
MainAxisAlignment.spaceBetween
MainAxisAlignment.spaceAround
MainAxisAlignment.spaceEvenly
Row(mainAxisAlignment: MainAxisAlignment.spaceEvenly, children: [ ... ])
Mobile App Development · Lecture 05

spaceBetween: no space at the edges. spaceAround: half space at the edges. spaceEvenly: equal space everywhere. Live demo: change the value and hot reload each one.

Alignment

crossAxisAlignment in a Column

In a Column, the cross axis is left ↔ right.

.start
.center
.end
.stretch
Column(crossAxisAlignment: CrossAxisAlignment.start, children: [ ... ])
Mobile App Development · Lecture 05

CrossAxisAlignment.start is the one students use most: it lines texts up on the left, like a form or a card. The default is center.

You can't see a SizedBox. You only see the gap it makes.
Mobile App Development · Lecture 05

SizedBox is the simplest way to add space. Most real screens are full of SizedBox(height: 8 / 16 / 24).

Widget 3 · Expanded

Expanded: take the free space

lib/main.dart
Row(
  children: [
    Container(width: 80, color: Colors.grey),
    Expanded(
      flex: 1,
      child: Container(color: Colors.blue),
    ),
  ],
)

Expanded makes its child fill the space that's left in a Row or Column.

Mobile App Development · Lecture 05

flex: 2 gets twice the space of flex: 1. Expanded only works directly inside a Row, Column or Flex.

Build it together

A contact card

lib/main.dartinside Scaffold
body: Center(
  child: Container(
    padding: const EdgeInsets.all(20),
    decoration: BoxDecoration(
      color: Colors.white,
      borderRadius: BorderRadius.circular(16),
    ),
    child: const Column(
      mainAxisSize: MainAxisSize.min,
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text('Ahmed Ali', style: TextStyle(fontSize: 22)),
        Text('Flutter Student'),
        SizedBox(height: 16),
        Row(children: [
          Icon(Icons.phone),
          SizedBox(width: 8),
          Text('091 234 5678'),
        ]),
      ],
    ),
  ),
),
